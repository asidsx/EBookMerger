# 📚 Universal Chapter & Book Merger (Сборщик электронных книг V11.0) 🚀

[![Build & Release](https://github.com/your-username/book-merger/actions/workflows/release.yml/badge.svg)](https://github.com/your-username/book-merger/actions/workflows/release.yml)
[![Formats](https://img.shields.io/badge/Форматы-FB2%20%7C%20EPUB%20%7C%20DOCX-00fff5)](#поддерживаемые-форматы)
[![Platforms](https://img.shields.io/badge/Платформы-Web%20%7C%20Android%20%7C%20Windows-bc13fe)](#установка-и-запуск)

Кроссплатформенное приложение для пакетного объединения, сортировки, предпросмотра и конвертации глав и томов электронных книг в единый файл формата **FB2**, **EPUB** или **ZIP-архив с обоими форматами**.

Интерфейс адаптирован как для **компьютеров**, так и для **смартфонов на Android** с сенсорным управлением и вкладками.

---

## 🌟 Основные возможности

- **📂 Мультиформатный импорт**:
  - Чтение и парсинг файлов **.fb2**, **.epub**, **.docx**.
  - Автоматическое извлечение глав, подзаголовков, книжных абзацев и встроенных иллюстраций.
  - Поддержка перетаскивания файлов (Drag & Drop) и стандартного диалога выбора.

- **📑 Управление главами и книгами**:
  - **Умная сортировка (`SmartSorter`)**: естественная сортировка номеров глав и книг (напр., *«Глава 1»*, *«Глава 2»*, *«Глава 10»*, *«Том 1-3»*).
  - Изменение порядка файлов книг и отдельных глав перетаскиванием (Drag & Drop) или стрелками **▲ / ▼** (для сенсорных экранов).
  - Инлайн-редактирование заголовков глав прямо в списке.
  - **Красные линии-разделители** (`── Конец файла: <Книга> ──`) между главами разных файлов.
  - Пакетный выбор чекбоксами и удаление ненужных глав.

- **👁 Встроенная читалка / Предпросмотр**:
  - Предпросмотр любой главы с сохранением книжной типографики и встроенных картинок.
  - Переключение тем оформления (*Cyber Dark*, *Warm Sepia*, *Pure Dark*).
  - Масштабирование размера шрифта.
  - Быстрая навигация по главам (*«Предыдущая»* / *«Следующая»*).
  - Подсчёт слов, символов и приблизительного времени чтения.

- **📦 Сборка и экспорт**:
  - Экспорт в **FB2** (валидный FictionBook 2.0 со встроенными бинарными изображениями).
  - Экспорт в **EPUB** (полный EPUB 2/3 контейнер с оглавлением `toc.ncx`, стилями и изображениями).
  - Экспорт в **ОБА формата** в виде ZIP-архива.
  - Возможность задать собственное название итоговой книги.

## 📱 Вкладки интерфейса (Android / Mobile)

Интерфейс приложения оптимизирован для работы на мобильных устройствах и разделен на 3 вкладки:

1. **📁 «Список файлов»**: очередь загруженных книг с форматами (`[FB2]`, `[EPUB]`, `[DOCX]`), количеством глав, кнопками перемещения и добавления.
2. **📑 «Список глав»**: список всех извлечённых глав с чекбоксами, инлайн-редактором названий, стрелками **▲ / ▼** и разделителями книг.
3. **👁 «Просмотр глав»**: читалка текста и иллюстраций с выпадающим списком глав, кнопками листания и регулировкой шрифта.

В нижней части экрана закреплена панель действий с большой кнопкой **«СОБРАТЬ КНИГУ»** и быстрыми инструментами.

## 🚀 Установка и запуск

### 1. Запуск Web-версии в браузере

```bash
# Клонировать репозиторий
git clone https://github.com/your-username/book-merger.git
cd book-merger

# Установить зависимости
npm install

# Запустить локальный сервер разработки
npm run dev
```

Приложение будет доступно по адресу: `http://localhost:3000`

---

### 2. Сборка для Windows (.exe)

```bash
# Собрать веб-версию и скомпилировать установщик/портативный .exe
npm run build:electron
```
Готовые исполняемые файлы будут сохранены в папке `dist_electron/`:
- `BookMerger-1.0.0-Setup.exe` (инсталлятор)
- `BookMerger-1.0.0-portable.exe` (портативная версия)

---

### 3. Сборка для Android (.apk)

```bash
# 1. Собрать веб-приложение в директорию assets Android
npm run build:android

# 2. Собрать APK через Gradle
cd android
./gradlew assembleRelease
# или для отладочной версии:
./gradlew assembleDebug
```
Готовые APK файлы будут находиться в `android/app/build/outputs/apk/`.

## 🤖 Автоматическая сборка в GitHub Actions

В репозитории настроен автоматический пайплайн сборки (`.github/workflows/release.yml`).

При создании нового релиза на GitHub или отправке тега версии (например, `v1.0.0`):
1. **GitHub Actions** автоматически собирает **Windows .exe** и **Android .apk**.
2. Готовые файлы автоматически прикрепляются к странице релиза:
   - `BookMerger-1.0.0-Setup.exe`
   - `BookMerger-1.0.0-portable.exe`
   - `BookMerger-Android-release.apk`
   - `BookMerger-Android-debug.apk`

## 📖 Как пользоваться

1. **Добавление книг**:
   - Нажмите кнопку **«+ Добавить»** или перетащите файлы `.fb2`, `.epub`, `.docx` в окно программы.
   - Либо нажмите кнопку **«Демо»**, чтобы протестировать на готовых примерах с иллюстрациями.
2. **Настройка порядка**:
   - Во вкладке **«Список файлов»** расположите тома в нужном порядке.
   - Во вкладке **«Список глав»** отредактируйте заголовки или удалите ненужные главы (например, дублирующиеся предисловия).
   - Нажмите **«Сортировать»** для автоматической упорядоченности по номерам.
3. **Предпросмотр**:
   - Нажмите **«Читать»** рядом с любой главой или перейдите во вкладку **«Просмотр глав»**.
4. **Сборка книги**:
   - В верхней строке введите желаемое **Название книги**.
   - Выберите формат выхода: **FB2**, **EPUB** или **ОБА**.
   - Нажмите **«СОБРАТЬ КНИГУ»** — файл скомпилируется и автоматически скачается на ваше устройство.
